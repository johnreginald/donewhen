# Security policy

## Report a vulnerability

Report it privately. Do not open a public issue.

1. Go to the **Security** tab of [johnreginald/donewhen](https://github.com/johnreginald/donewhen).
2. Click **Report a vulnerability**.
3. Describe the problem. Include what it affects, how to reproduce it, and the impact.

This uses GitHub private vulnerability reporting. Only the maintainers can see your report.

## What to expect

- We acknowledge your report.
- We investigate the problem and send updates in the private report.
- We fix the problem and publish a release. Then we disclose it. We credit you if you want.
- Do not disclose the issue publicly until we publish a fix.

## Supported versions

Only the latest release gets security fixes. Update to the latest release before you report, if you can.
