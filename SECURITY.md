# Security policy

## Report a vulnerability

Report it privately. Do not open a public issue.

1. Go to the **Security** tab of [johnreginald/donewhen](https://github.com/johnreginald/donewhen).
2. Click **Report a vulnerability**.
3. Describe the problem: what it affects, how to reproduce it, and the impact.

This uses GitHub private vulnerability reporting. Only the maintainers can see your report.

## What to expect

- We acknowledge your report.
- We investigate and keep you updated in the private report.
- We fix it and publish a release, then disclose it with credit to you if you want.
- Please do not disclose the issue publicly until a fix is released.

## Supported versions

Only the latest release gets security fixes. Please update before you report, if you can.
