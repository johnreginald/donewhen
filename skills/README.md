# Skills

Agent skills for working with DoneWhen.

- **`donewhen/`** — how to use DoneWhen over its MCP tools: the tool table, writing tickets (`TICKETS.md`), turning a spec into tickets, done-when checklists and the finishing steps.

Install it for Claude Code by linking it into your skills folder, so edits here apply everywhere:

```bash
ln -s "$(pwd)/skills/donewhen" ~/.claude/skills/donewhen
```
