# Skills

Agent skills for working with Raenil.

- **`raenil/`** — how to use Raenil over its MCP tools: the tool table, writing tickets (`TICKETS.md`), turning a spec into tickets, done-when checklists and the finishing steps.

Install it for Claude Code by linking it into your skills folder, so edits here apply everywhere:

```bash
ln -s "$(pwd)/skills/raenil" ~/.claude/skills/raenil
```
