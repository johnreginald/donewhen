# Skills

Agent skills for work with DoneWhen.

- **`donewhen/`** — how to use DoneWhen over its MCP tools. It contains the tool table, ticket writing rules (`TICKETS.md`), the steps to turn a spec into tickets, done-when checklists, and the finishing steps.

To install it for Claude Code, link it into your skills folder. Then edits here apply everywhere.

```bash
ln -s "$(pwd)/skills/donewhen" ~/.claude/skills/donewhen
```
